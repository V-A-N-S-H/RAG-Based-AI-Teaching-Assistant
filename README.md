# RAG Based AI Teaching Assistant

A simple AI Teaching Assistant built using RAG (Retrieval-Augmented Generation), Python, Flask, and Ollama.  
This project helps students ask questions related to a course and get answers with the exact video name and timestamps where the topic was taught.

---

# About The Project

I made this project to create an AI assistant that can answer questions from course videos like a real teaching assistant.

The system:
- Converts course videos into audio
- Creates transcripts using Whisper AI
- Splits the transcript into chunks
- Generates embeddings using Ollama
- Finds the most relevant content using cosine similarity
- Uses an LLM to generate human-like answers

The AI also tells students:
- Which video contains the answer
- At what timestamp the topic is explained

# Installation

## Step 1 — Clone the Repository

```bash
git clone https://github.com/V-A-N-S-H/RAG-Based-AI-Teaching-Assistant.git
cd RAG-Based-AI-Teaching-Assistant
```

---

## Step 2 — Install Requirements

```bash
pip install flask pandas numpy scikit-learn requests joblib openai-whisper
```

---

## Step 3 — Install FFmpeg

Download and install FFmpeg:

Windows:
https://ffmpeg.org/download.html

After installation, add FFmpeg to PATH.

---

## Step 4 — Install Ollama

Download Ollama:

https://ollama.com/

Pull required models:

```bash
ollama pull llama3.2
ollama pull bge-m3
```

---

# How To Run The Project

## Step 1 — Convert Videos to Audio

```bash
python 01_process_video.py
```

## Step 2 — Generate Transcript Chunks

```bash
python 02_Creating_Chunks.py
```


## Step 4 — Create Embeddings

